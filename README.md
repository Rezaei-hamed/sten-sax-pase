# 🪨 Sten, Sax, Påse ✂️📄

Ett enkelt och roligt **Sten, Sax, Påse-spel i Python**! 🎮

Du spelar mot datorn och den som först får **3 poäng vinner**. 🏆

## 🎮 Hur spelar man?

När spelet startar får du välja:

* `s` = 🪨 Sten
* `x` = ✂️ Sax
* `p` = 📄 Påse

Skriv ditt val och tryck på **Enter**.

Datorn väljer sedan slumpmässigt och programmet visar vem som vann rundan.

### 📋 Exempel

```text
s: Sten, x: Sax, p: Påse
Vänligen välj ett av alternativen ovan:

s

Datorn valde: x
Du: 1 - Datorn: 0
```

Spelet fortsätter tills någon får **3 poäng**.

Om båda väljer samma sak blir det lika:

```text
Lika! Testa igen!
```

När spelet är slut visas till exempel:

```text
Grattis! Du vann! 🎉
```

eller:

```text
Tyvärr, datorn vann! 🤖
```

## 🚀 Starta spelet

Öppna terminalen och kör:

```bash
python main.py
```
